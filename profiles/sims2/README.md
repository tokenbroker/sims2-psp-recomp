# The Sims 2 PSP profile

USA ULUS-10031 only. The supported executable hash and code-generation metadata
are in config/identity.json. Game files and generated units are local inputs,
not repository content.

- [Project overview](../../README.md)
- [Build and launcher instructions](../../docs/BUILD.md)
- [Settings and controls](../../docs/SETTINGS.md)
- [Status and limitations](../../docs/STATUS.md)
- [Third-party notices](THIRD_PARTY.md)

Run the root `build.py` with your own ISO. The setup fetches pinned development
dependencies, validates/extracts the disc, generates AOT code and builds a local
RecompLauncher folder. Keep all generated/prepared output private.
